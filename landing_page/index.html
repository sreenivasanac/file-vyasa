Powerful Features for Every File

FileVyasa extracts meaningful information from your files so you can find anything instantly

Smart Content Extraction

Extracts text from PDFs (with OCR), Office documents, code files, and more. Understands what's inside your files.

AI Image Description

Uses local AI (Ollama LLaVA) to describe what's in your photos and images. Find images by their content.

Media Transcription

Transcribes audio and video files locally using Whisper. Search through your podcasts, meetings, and recordings.

Privacy First

Your files never leave your computer. Use local models with Ollama or bring your own API key for cloud LLMs.

Lightning Fast

Parallel processing with configurable workers. Scan and process thousands of files in minutes, not hours.

Native Desktop App

Built with Tauri for a fast, native experience. Available for macOS with Windows and Linux support coming soon.

Agentic File Organization

Let AI propose the perfect folder structure—you stay in control. Review, approve, or reject every action before anything moves.

Human-in-the-Loop AI

FileVyasa will never move or rename files without your explicit approval. The AI proposes, you decide. Every action is reversible with built-in rollback.

Smart Clustering

AI groups related files together based on content, not just extensions. Similar documents, related projects, and thematic content automatically clustered.

Folder Planning Board

Visual preview of proposed folder structure before any changes. See exactly where each file will go, edit folder names, and adjust the plan.

Per-File Approval

Accept or reject each proposed move individually. Confidence indicators (green/yellow/red) help you quickly review AI suggestions.

Rollback Anytime

Every move and rename is logged with rollback metadata. Changed your mind? Undo any action—even days later. Your files are always safe.

Duplicate Detection

Hash-based detection finds true duplicates across your folders—even when filenames differ. Reclaim storage without risking important files.

Learns Your Style

FileVyasa remembers your folder preferences, naming conventions, and past decisions. Future suggestions get smarter over time.
